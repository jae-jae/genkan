# Demo service icons

These SVGs are service logos taken from **[homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons)**,
which is licensed under the **Apache License 2.0** (<https://github.com/homarr-labs/dashboard-icons/blob/main/LICENSE>).

They are used only as fixtures: the Playwright screenshot spec uploads them to a throw-away instance to render the
README images. They are not embedded in the Genkan binary or the Docker image.

The logos are trademarks of their respective owners and are used here only to identify the services they belong to.
